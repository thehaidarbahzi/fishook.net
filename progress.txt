### Session Hook (Task 10)
- Created `src/hooks/useSession.ts` - Hook fetch session, handle loading/error/expired
  - Selector store satu-per-satu (session, status, error + actions) agak hanya re-render saat nilai berubah
  - `load()` (useCallback) - set status loading → `fetchSession()` → `setSession(data)`; gagal → `setError(message)`; reusable untuk tombol retry (kasus Cookie ditolak / port Express mati)
  - `useEffect` panggil `load()` saat mount (GET idempoten, aman di React StrictMode dev)
  - `isExpired()` - derived check `expiresAt <= Date.now()` (PRD 2.2); retry setelah expired membuat backend generate webhook baru
  - Return: `{ session, status, error, isExpired, load, clear }` - hook pure, toast diserahkan ke komponen
